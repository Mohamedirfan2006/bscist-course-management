# BSCIST Course Management System

A web-based course management system for BCA III YR. Manage courses, students, faculty, assignments and results from a single page.

## Features
- Dashboard with totals, pending grading and a recent-activity feed
- Courses: add, edit, delete, assign faculty, see enrolment counts
- Students: add, edit, delete, enrol in courses
- Faculty: add, edit, delete, courses taught are derived automatically
- Assignments: linked to a course with due date and maximum marks
- Results: grading workbench with live percentage and grade stamps (A+ to F), searchable result ledger
- Cascading deletes keep data consistent; forms are validated

## Run locally
Open `index.html` in any modern browser. No installation needed.
